# RetroCoreTracer for F-BB (RetroCoreTracer-FBB)

Visual RTL Z80 CPU Tracer with Step Execution & Backstepping, integrated as an F-BB PPA 5.1 & DPPA v1.0 Plugin.

## Architecture
- **PPA 5.1 (Peripheral Plugin Architecture)**: Verilog Z80 RTL and Verilator simulation harness daemon.
- **DPPA v1.0 (Dashboard Pane Plugin Architecture)**: Native ES Module Dockview pane (`pane/`) rendering visual bus tracer and inspector.
